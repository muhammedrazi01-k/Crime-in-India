# 🇮🇳 Crimes in India – Interactive Dashboard

## 📌 Project Overview

The **Crimes in India Dashboard** is a data visualization project designed to analyze and explore crime reports across various cities in India. It provides a comprehensive overview of reported crimes, victim demographics, weapons used, geographical distribution, yearly crime trends, and case closure statistics.

The dashboard transforms crime data into meaningful visual insights, helping users understand crime patterns and distributions across India.

## 📊 Dashboard Highlights

- **Total Crimes Reported:** Displays the overall number of reported crime cases.
- **Victim Gender Analysis:** Shows the distribution of crime victims by gender.
- **Weapon Analysis:** Visualizes the different types of weapons used in reported crimes.
- **Year-wise Crime Analysis:** Tracks crime reports from 2020 to 2024.
- **Geographical Analysis:** Highlights crime distribution across major Indian cities.
- **Case Closure Analysis:** Compares closed and pending crime cases.
